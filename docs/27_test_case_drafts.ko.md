# 관측 요청에서 테스트 초안 만들기

**문제 발견 → 근거 확인 → 테스트로 남기기**의 다음 단계를 제공합니다.
실패하거나 느린 요청을 골라 JSON 초안과 JUnit 테스트 파일을 만들 수 있습니다.
0.4.0부터 제공하는 기능이며, 원래 요청을 그대로 재현하는 기능은 아닙니다.

![느린 요청을 기대 상태 200, 제한 500 ms로 검토한 테스트 초안](assets/reqover-test-case-draft.png)

## 사용하는 흐름

1. 요청 그래프에서 요청을 선택하거나 Requests에서 요청을 펼칩니다.
2. `Create test draft`를 누르면 Test drafts로 이동합니다. 출처 요청, route,
   관측 상태, 기록 시간과 실행 메서드 목록이 그 요청에 연결됩니다.
3. 시험할 실제 경로와 기대 HTTP 상태를 직접 입력합니다. 원래 503이 나왔다고
   기대 상태도 503으로 채우지 않습니다. 고친 뒤 200을 기대한다면 200을 입력합니다.
4. 필요하면 허용할 클라이언트 처리 시간을 정하고 시험 대상과 입력을 검토합니다.
   필드를 바꾸면 기존 검토 확인이 해제됩니다.
5. JSON 초안 또는 기본 비활성화된 JUnit 파일을 다운로드합니다.

JUnit 내보내기는 GET/HEAD만 지원합니다. POST·결제·메일 발송은 초기화와 중복 실행
정책부터 정해야 하므로 JSON 초안까지만 만듭니다. 경로의 `{id}`와 `**`는 실제
시험 경로로 바꿔야 하고, query·본문·인증 입력은 이번 버전에서 지원하지 않습니다.

초안은 현재 페이지의 메모리에만 있습니다. 새로고침하면 사라지며, localStorage나
외부 서버에 저장하지 않습니다. 필요한 초안은 다운로드한 파일로 남깁니다.

## 왜 자동 실행하지 않나

현재 수집 데이터에는 실제 path 값, query, 본문, 인증 헤더가 없습니다. 정규화된
route만 가지고 원래 실패를 재현했다고 말할 수 없기 때문입니다. 같은 API여도
입력이나 권한 상태가 다르면 다른 경로를 실행할 수 있습니다.

생성된 Java는 UI에서 검토했더라도 `@Disabled`가 붙습니다. 코드를 읽고 시험용
입력과 인증을 로컬에서 보완한 뒤, 명시적인 local/QA 대상과 함께 직접 활성화합니다.
대상은 `reqover.test.baseUrl` 시스템 속성으로 지정하며 기본 운영 주소는 없습니다.
주소에는 계정 정보·경로·query·fragment를 넣을 수 없고 redirect도 따르지 않습니다.
내보내기 자체는 HTTP 요청을 실행하지 않습니다.

기대 상태는 사용자가 정한 값입니다. 시간 제한은 `System.nanoTime()`으로 재는
클라이언트 요청 전체 시간입니다. 리포트의 서버 어댑터 관측 시간과 측정 경계가
다르므로 자동으로 복사하지 않습니다. 한 번의 테스트 시간은 p95나 TPS가 아닙니다.

생성된 파일은 Java 17 기본 HttpClient와 JUnit 5를 사용합니다. 별도의 Reqover
테스트 라이브러리는 필요 없습니다. 출처 요청과 메서드 이름은 문자열 상수로
남기며, Java 주석이나 실행 코드에 원문으로 끼워 넣지 않습니다.

## 파일과 보안

JSON의 종류는 `reqover-http-test-draft`이며 coverage report JSON과 다릅니다.
`replayable: false`를 유지하고 관측 정보와 요청 경로·기대 결과를 분리합니다.
검토 전 JSON도 내보낼 수 있지만 상태는 `review-required`입니다.

인증정보·쿠키·본문을 복사하지 않습니다. 다만 직접 입력한 경로나 기존 코드 이름은
민감할 수 있으므로 생성 파일을 자동으로 커밋하지 않습니다. API 키·비밀번호·토큰은
코드와 내보내는 파일에 넣지 않습니다. CI의 기존 리포트 저장 동작도 그대로 유지합니다.

## 아직 다음 단계인 것

원본 입력 수집과 마스킹, 완전한 요청 재현, 화면에서 테스트 실행, 실행 결과 import,
부하 테스트와 통제된 run의 개선 비교는 별도 단계입니다.
이번 개선은 **찾아낸 요청의 근거를
검토 가능한 테스트 파일로 옮기는 연결**을 실제로 만든 것입니다.

생성 로직·Java 컴파일·브라우저 검증 방법은 [영문 안내](27_test_case_drafts.md)에 있습니다.
