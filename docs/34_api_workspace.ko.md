# API 그룹과 재테스트 대상 선택 (미출시)

현재 소스 브랜치에 추가한 기능이며 Maven Central·GitHub의 0.4.2 배포본에는 없습니다.
수집기·coverage JSON·CLI·CI Action 계약과 기존 Request map·Retest map은 유지합니다.

## 두 가지 보기

![120개 API 합성 기록을 사용하는 미출시 라이트모드 그룹 화면](assets/reqover-api-groups.png)

![합성 기록의 API 통계와 상위 20개 선택 화면](assets/reqover-api-workspace.png)

첫 구현 단계의 실제 renderer로 그린 120개 API·660건 합성 fixture입니다. 운영 증거나 성능
벤치마크가 아닙니다. 그룹과 API 행 모두 페이지당 20개로 DOM 증가를 제한합니다.
후속 초기화·그룹 제한·출처 안내 컨트롤은 아직 사진에 없으며 [사용성 보완 기록](35_dashboard_usability_review.ko.md)을 참고합니다.

Groups는 경로 앞의 1~3개 구간으로 API를 묶습니다. `/api/v1/...`처럼 공통 접두사가
있으면 Group depth를 늘립니다. 자동으로 발견한 서비스나 의존성 클러스터가 아닙니다.
검색·상태·건수·p95 필터는 그룹 집계를 좁히고, 화면 상단 전체 통계는 유지합니다.

API list에서는 관측 건수·비중, 평균·p95·최대 처리 구간, 시간 표본 수, 미확인 상태,
4xx·5xx 건수와 비율을 봅니다. 열 이름을 눌러 정렬하고 미측정 시간은 양방향 모두
맨 뒤에 둡니다. 한 페이지 20개이며 페이지·필터·보기 전환 후에도 선택을 유지합니다.

- 그룹 클릭: 해당 경로 그룹의 API 목록으로 이동. Groups로 돌아가면 그룹 제한 해제.
- Select top 20: 현재 필터·정렬의 상위 20개를 기존 선택에 추가. 기존 선택을 대체하지 않음.
- 페이지 맨 위 체크박스: 현재 페이지 선택·해제.
- Clear selection: 모든 선택 해제.
- API 이름 클릭: 기존 코드 화면으로 이동해 해당 API를 검색.
- Clear group: 경로 그룹 제한만 해제. Reset filters: 검색·상태·건수·p95·그룹 제한 해제.
  선택·정렬·그룹 깊이는 유지.

선택한 API 수와 전체 보관 요청 대비 비중, 현재 필터 밖의 선택 수를 함께 표시합니다.
호출량은 우선순위의 한 근거일 뿐입니다. 드문 결제·권한 API도 중요할 수 있습니다.
HTTP 오류 비율 분모는 확인된 최종 상태이며, 예상한 4xx를 테스트 실패로 단정하지 않습니다.

## 테스트 초안 연결

Create drafts는 선택 API마다 최근에 남아 있는 대표 요청 하나를 기존 초안 편집기에
추가합니다. 실제 경로·기대 상태·인증·허용 시간은 추측하지 않습니다. 각 초안을
별도로 검토하며 JUnit은 여전히 기본 비활성입니다. 같은 API·요청 ID·시작 시각은
기존 초안을 재사용하고 편집 내용을 유지합니다. 실행 전 사용 가능한 출처와 누락 수,
생성 후 새 초안·재사용 수를 표시합니다.

Export draft bundle은 `reqover-http-test-draft-bundle`, schema 1 JSON을 만듭니다.
선택 목록·초안 목록·원본 상세 없는 API 목록·상세 상한 100·검토 필요 상태와
`replayable: false`, 원본 리포트의 생성 시각을 포함합니다. CLI coverage JSON,
비교 요약, Postman/JMeter 시나리오 또는 실제 실행 결과가 아닙니다. 묶음 불러오기는 아직 없습니다.

**통계는 전체 보관 요청 집계지만 초안의 출처는 최근 100개 HTTP 상세입니다.**
통계는 있어도 상세가 없는 API는 누락 목록으로 명시합니다. 검증용 합성 기록
120개 API·660건에서는 초안 16개, 상세 없는 API 104개를 표시합니다.
없는 요청이나 원래 입력을 만들어 넣지 않습니다.

## 지표와 안전

그룹 평균은 유효 처리 시간 합계/시간 표본 수입니다. API별 평균을 단순 평균 내지
않습니다. API별 p95를 합쳐 그룹 p95를 만들 수 없어서 그룹 p95는 표시하지 않습니다.
어댑터 처리 구간이지 네트워크 응답시간·CPU 시간·서비스 전체 TPS가 아닙니다.
이미 잘린 coverage JSON을 다시 그리면 그 파일에 없는 상세는 복원할 수 없습니다.

선택과 초안은 페이지 메모리에만 남고 새로고침하면 사라집니다. 내보내기에 내부 API·코드
이름이 포함될 수 있어 자동 공개하지 않습니다. 재실행·운영 요청 차단·외부 통신은 없습니다.
JavaScript 없이도 기존 정적 표를 읽을 수 있고 새 workspace는 숨겨 둡니다.

## 검증과 트러블슈팅

Java report/CLI 테스트, Node 모델 테스트, 실제 5건 예제와 120개 API 합성 브라우저
검증을 수행합니다. 정렬·페이지·선택·누락 내역·초안 검토·코드 이동·모바일·다크모드와
기존 관계도·비교·옛 파일·스크립트 없는 화면을 확인합니다. 명령은 [영문 안내](34_api_workspace.md)에 있습니다.

- 옛 파일에 상세 없음: 없는 시간이나 요청을 생성하지 않고 데이터 없음 표시.
- 기존 표의 첫 열 40% 규칙이 새 체크박스 열에 전파: `.api-table`에만 열 폭과
  table-layout 규칙을 지정하고 브라우저에서 체크박스 열 폭을 검사.
- ISO 시각의 소수 자릿수가 다름: 문자열 순서가 아닌 실제 시각과 나노초 소수부로
  최신 대표 요청을 결정하는 회귀 테스트 추가.

5분 구간과 히트맵은 미출시 [규모별 보기](37_scale_views.ko.md)에 추가했습니다.
별도의 미출시 [재테스트 워크플로](39_retest_workflow.ko.md)에 파일 이력·외부 시나리오
형식·제한된 로컬 실행을 추가했습니다. 원래 트래픽 재현이나 정기 재실행은 없습니다.
