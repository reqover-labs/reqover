# 규모별 보기 구현 계획

2026-10-12. 기존 요청/코드/CLI 계약을 유지하면서 다음 세 단계 연결을 추가한다.

- 전체: 보관 HTTP 요청 전체의 5분 구간 x 어댑터 처리 시간대 히트맵.
- 그룹: 선택한 구간/시간대의 정확한 API 통계를 기존 경로 그룹 화면으로 전달.
- 상세: 해당 범위에 실제로 남아 있는 최근 요청 상세와 기존 Request map으로 이동.

Java에서 최근 100개 제한 전에 집계한다. 구간 전체와 각 시간대의 API별 통계를
RequestSummary로 별도 계산하고 백분위수를 합치거나 평균 내지 않는다.
최근 비어 있지 않은 256개 구간까지만 보낸다. 생략한 요청 수·시각 범위 외의 요청을
명시하며, 빈 구간을 무관측으로 보여주되 트래픽 없음이나 성공으로 단정하지 않는다.

선택한 시간/지연 범위 밖의 요청으로 초안을 만들지 않는다. 전체 통계가 있어도
최근 100개 중 일치하는 상세가 없으면 누락으로 표시한다. 선택과 초안은 메모리 상태이며
히스토리 영구 저장·자동 재실행·부하 생성은 추가하지 않는다.

검증: 100개보다 많은 기록, 경계값·미완료·음수 시간·5xx·비HTTP·구간 상한·극단 시각을
Java 테스트로 확인한다. JS 모델에서 구간 선택·출처 필터를 검사한다.
현재 브라우저 로컬 파일 자동 조작 제한을 우회하지 않는다. 시각적 E2E·모바일 재검증은
별도로 미완료 표시하고 단위/통합 검증을 완료한다.
