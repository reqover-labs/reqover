# 워크스페이스 선택·비교·빈 상태 보완

2026-10-23. PR #53의 미출시 소스 후속 작업이다. 배포된 0.4.2의 변경 사항이 아니다.
이번 범위는 기존 화면에서 API를 선택하고, 실행/관측 이력을 불러와 비교하는 동작이다.

## 확인한 문제와 수정

| 재현 동작 | 수정 후 기대 결과 |
| --- | --- |
| 관계도 상세에서 `GET /orders/1` 링크 선택 | 정확한 endpoint 필터를 사용. `/orders/10`·대소문자가 다른 경로를 함께 선택하지 않음 |
| Run history의 Baseline을 Not selected로 바꾼 뒤 검색 | 선택 해제 유지. 임의의 두 번째 실행을 다시 선택하지 않음 |
| Current를 해제한 뒤 검색하거나 선택한 기록 제거 | Current가 비어 있는 상태 유지. 다른 기록을 자동으로 대신 선택하지 않음 |
| Recordings 기준 선택을 해제한 뒤 추가 파일 import | 선택 해제 유지. 최초 import 때만 기본 Current/Baseline 선택 |
| Current와 Baseline에 같은 실행 또는 관측 기록 선택 | 다른 기록을 선택하라는 상태 표시, 자기 자신과의 비교 표는 생성하지 않음 |
| 실행/관측 이력이 없거나 검색 결과 없음 | 빈 표 대신 No runs loaded / No recordings loaded / No runs match 상태 표시 |
| 시나리오 이름이 없거나 사례가 미검토 | 비활성 내보내기 버튼과 함께 해당 유효성 오류 표시 |

시나리오 명령 버튼과 이력 행 버튼에 테마 글자색을 명시하고, 긴 메타데이터의 줄바꿈을 허용했다.
이는 소스 수준 보완이며 실제 라이트/다크 대비·모바일 배치 확인을 대신하지 않는다.

## 진행과 검증

- [x] 기존 사용성·트러블슈팅 기록과 현재 controller 검토.
- [x] 정확한 링크·선택 보존·빈 상태 회귀 검사를 먼저 실행해 3개 실패 재현.
- [x] 동작 수정 후 같은 회귀 검사 5개 통과.
- [x] 전체 독립 Node 모델/controller/생성 Java 검사 48개 통과.
- [x] Java report 79개·CLI 25개 회귀 검사 통과, 실패·오류 0.
- [x] 로컬 fixture 실제 요청 8건으로 실패 전 exit 1 → 수정 후 exit 0, 실행 이력 2개·관측 이력 1개·보고서/비교 생성 확인.
- [x] 갱신된 CLI로 기존 120개 API 합성 기록의 HTML 재생성. 유효성 상태·정확한 endpoint 선택·자기 비교 방지 코드 포함 확인.
- [ ] 최신 화면 실제 브라우저 E2E·모바일·라이트/다크·다운로드 확인.

DOM 대역은 선택 값과 controller 동작 검사용이다. 실제 페이지 렌더링 검증으로 보고하지 않는다.
도구에서 차단된 로컬 페이지를 다른 URL·브라우저·간접 자동화로 우회하지 않았다.

## 실제 화면에서 이어서 확인할 순서

| 화면 | 확인 순서 |
| --- | --- |
| 작은 기록 | Overview → 코드 선택 → API 링크 → 정확히 한 endpoint 필터 확인 |
| 중간 기록 | Groups → API list → 필터 → 체크박스 → 다른 보기 → 선택 유지 |
| 큰 기록 | Distribution → 5분 구간 → 처리 시간대 → Groups/API → 같은 범위의 Request map |
| Scenario | 빈 상태 → 초안 추가 → 이름 비우기 → 오류 상태 → 입력 복구 → 저장/import → 재검토 |
| Run history | 2개 import → 비교 기준 해제 → 검색 → 해제 유지 → 동일 ID 비교 차단 → Current 제거 |
| Recordings | 빈 상태 → 2개 import → 기준 해제 → 추가 import → 해제 유지 → 동일 ID 비교 차단 |
| 표시 상태 | 390px·긴 경로/이름·키보드 초점·라이트/다크·빈 결과·파일 오류 |

Run history의 검색은 목록만 좁힌다. Current/Baseline은 계속 유지하며 비교 결과도 유지한다.
메뉴 이동·새로고침·파일 저장의 동작은 기존 [워크플로 문서](39_retest_workflow.ko.md)를 따른다.
