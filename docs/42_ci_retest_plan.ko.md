# 사이드바·시나리오 CI 후속 계획

2026-10-23. 사용자가 앞선 1~4번의 남은 작업과 사이드 스크롤 개선을 요청했다.

- 대회 피드백은 수신한 내용만 기록한다. 오늘 기능검증 결과는 아직 전달받지 않았다.
- 사이드바의 짧은 창 넘침·메뉴 선택 표시·스크롤바·키보드 접근을 기존 테마에 맞춰 보완한다.
- 최신 화면의 실제 브라우저 접근은 이전 도구 제한으로 미완료다. 우회하지 않는다.
- 저장된 schema-1 시나리오를 source-built CLI로 실행하는 별도 composite Action을 제공한다.
- Action은 샘플 앱 기동·로컬 준비 확인·순차 검사·정리를 수행한다. 기본 권한은 contents:read.
- 결과 JSON/HTML·고정 형식 요약·선택적 기준 실행 비교를 제공하며, 실패 뒤에도 opt-in artifact를 올린다.
- 앱 기동 실패·입력 오류는 종료코드 2, 조건 불일치/미실행은 1, 전체 통과는 0으로 구분한다.
- PR CI에 샘플 실행을 연결한다. 예약 실행은 자동 활성화하지 않고 복사 가능한 opt-in 예제로 문서화한다.
- 변경은 현재 PR #53에서 검증한다. 화면 검증이 남은 동안 머지·릴리스 완료로 표시하지 않는다.

검증: Python 실행기 통합 시험(실제 JVM/루프백), Node 모델/controller, Java report/CLI,
GitHub의 새 CI job을 확인한다. 생성 결과·서버 로그는 ignored build/tmp 안에만 둔다.
